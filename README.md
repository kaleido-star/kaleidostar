# カレイドスターの言葉

『カレイドスター』に関連する、[kaleidostar.jp](https://kaleidostar.jp/test.html) の表示文言データです。作品・権利者・GitHub の公式リポジトリではありません。

`quotes.json` に表示する29件の文言、話者、出典、確認区分を記録します。内訳は公式掲載の劇中の言葉8件、本編を視聴して発話と話者を確認した19件、本編外のラジオコーナー名・ファン呼称2件です。「本編視聴確認済み」は漢字や句読点について公式の表記があることを意味しません。

文言の追加・修正は [CONTRIBUTING.md](CONTRIBUTING.md) を読んで、`quotes.json` を変更する Pull Request で提案してください。話数・場面・出典や確認方法を PR に書いてください。採用前に管理者が内容を確認します。PR がマージされてもサイトには即時反映されず、確認後にサイト側へ取り込んで配備します。

このリポジトリにはサイトの実装、サーバー設定、動画・音声・文字起こし全文を含めません。各文言の出典はデータ内の `source` に記録しています。作品中の台詞などの権利はそれぞれの権利者に帰属します。
